# Grill-With-Docs

Combines rigorous requirements grilling with inline domain modeling, glossary updates in `CONTEXT.md`, and Architectural Decision Records (ADRs).

## Workflow

1. **Conduct a grilling interview:** Map the problem as a decision tree and interview branch-by-branch.
2. **Sharpen terminology inline:** Capture domain terms and entity models in `CONTEXT.md` as decisions are reached.
3. **Record architectural trade-offs:** Document key trade-offs in `docs/adr/` with context, alternatives considered, and consequences.
4. **Establish clear boundaries:** Ensure all non-goals, data contracts, and test seams are documented before implementation.
