# Shared workflows

Versioned workflows shared across assistants.

## Default software change

1. Investigate using project evidence.
2. Report the diagnosis and proposed change.
3. Request implementation approval.
4. Create a ticket in the project's configured tracker.
5. Start the configured coding agent in an isolated checkout.
6. Implement and test locally.
7. Commit, push, and open a pull request.
8. Return the pull request, checks, and trace links.

GitHub Issues is the default when the project does not configure another tracker.
