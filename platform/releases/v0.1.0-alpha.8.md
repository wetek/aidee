# Aidee v0.1.0 Alpha 8

## Purpose

Enable autonomous host operations and sudo privileges for the Aidee controller, automate default cron jobs during setup, and default dashboard sessions to 30 days.

## Autonomous host management & zero-SSH operations

- Configures passwordless sudo for the `aidee-controller` service account (`/etc/sudoers.d/aidee-controller`).
- Adjusts systemd hardening drop-ins to allow privilege escalation and full host fleet management.
- Enables autonomous fleet resource rebalancing without manual host terminal commands.

## Automated default cron jobs

- Provisions both the Daily Aidee Update Check (`every 24h`) and Fleet Health Watchdog (`every 6h`) automatically during setup.
- Provides `install-default-crons.py` and `install-health-watchdog.py` CLI tools.

## 30-day dashboard session TTL

- Sets `HERMES_DASHBOARD_BASIC_AUTH_TTL_SECONDS=2592000` (30 days) by default across controller and assistant container environments.
- Ensures persistent login cookies for mobile Safari and Telegram in-app webviews.
