# Aidee v0.1.0 Alpha 10

## Purpose

Activate Unslop and Matt Pocock-grade software engineering standards by default across assistant runtimes.

## Unslop communication standards

- Embeds concise response budgets (default ≤120 words), plain direct speech, zero AI filler or sycophancy, and execution-backed deliverables in assistant `SOUL.md`.
- Writes active `SOUL.md` directly into `runtime_dir / "SOUL.md"` with `CONTAINER_UID` (`10000`) permissions.

## Software engineering directives

- Configures Matt Pocock-grade engineering standards by default for `coding` and `project` assistants:
  - **Test-Driven Verification:** Mandatory real test execution (`tsc`, `pytest`, `vitest`) before completing tasks.
  - **Systematic Debugging:** 4-phase root-cause analysis prior to edits.
  - **Pre-Commit Code Reviews:** Quality gates and minimal atomic diffs.
  - **Structured Documentation:** Clear PRs with cited action items.
