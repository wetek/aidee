# Aidee v0.1.0 Alpha 21

## Purpose

Skip the Hermes systemd prompt during fleet apply. Alpha 20 stopped at
`Start the gateway automatically on login/boot with systemd?` because
streamed commands inherited the SSH TTY.

This tag is also the first release the Alpha 20 controller can announce
with the Telegram Start update notice.

## Apply

- Streamed updater commands close stdin so Hermes does not prompt.
- `hermes gateway install` passes `--start-on-login` and reads `/dev/null`.

## Migration

No new state migration. Re-run the fleet updater after this tag is active.

## Validation

- Unit tests cover streamed stdin and the gateway install flags.
- Repository validation and unit tests pass.

## Rollback

Roll back host and assistant image state to `v0.1.0-alpha.20`.
