# Aidee v0.1.0 Alpha 3

## Purpose

Require verified private dashboard access and Telegram bot branding before controller setup completes.

## Included

- Tailscale as the default automated phone-access method.
- SSH tunnel as a temporary alternative.
- Cloudflare shown as a planned option.
- Telegram DM pairing as the recommended owner authorization method.
- Adaptive avatar generation or JPG upload.
- Approved Telegram name, descriptions, commands, avatar, and dashboard menu button.
- Telegram Bot API read-back verification.
- Phone dashboard confirmation.
- Server-generated onboarding status.

## Completion

The setup program reports `Controller setup complete` only after:

- Telegram owner access is verified.
- Telegram branding is applied and read back.
- The owner confirms that the dashboard opens from their phone.

Assistant provisioning remains outside this release.
