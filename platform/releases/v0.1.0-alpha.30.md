# Aidee v0.1.0 Alpha 30

## Purpose

Install the Langfuse Python SDK into the assistant Hermes virtual environment
(`/opt/hermes/.venv`) instead of Debian system Python to respect PEP 668 and allow
clean image builds.

## Apply

- Change assistant image Dockerfile to install Langfuse with `--python /opt/hermes/.venv`.
- Image build and assistant containers verified.

## Validation

- Unit tests and repository validation pass.
