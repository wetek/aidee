# Aidee v0.1.0 Alpha 28

## Purpose

Expose the Fleet overview and assistant overview dashboards on top-level
navigation paths (`/overview`) instead of root overrides so Hermes Agent renders
them reliably in the sidebar navigation without root redirection conflicts.

## Apply

- Change `aidee-overview` and `aidee-assistant-home` manifest tab paths to `/overview`
  with `position: "start"`.
- Remove `"override": "/"` from plugin manifests to avoid Hermes suppressing sidebar
  navigation items.

## Validation

- Unit tests and repository validation pass.
