# Aidee v0.1.0 Alpha 15

## Purpose

Finish the Alpha 14 host apply on existing VPS installs. The administration
helper failed to start because it imported onboarding state from a path that
exists only in the source tree.

## Administration helper install

- `install-admin-helper.sh` copies `onboarding_state.py` next to the installed
  helper at `/usr/local/lib/aidee`.
- `assistant_state.py` loads that module from the install directory first, then
  from `platform/setup` in a source checkout.
- A regression test imports the installed layout and fails if the helper cannot
  start without `/opt/aidee/source` on `sys.path`.

## Migration

No new state migration. Re-run the fleet updater after this tag is active.

Alpha 14 may have already activated `/opt/aidee/source` and left assistants on
their previous image. Apply Alpha 15 to restart the helper and continue
reconciliation.

## Validation

- Unit tests cover the installed helper import path.
- Repository validation and unit tests pass.

## Rollback

Roll back host and assistant image state to `v0.1.0-alpha.14` only if the
Alpha 14 helper was already healthy. Hosts that failed during the Alpha 14
apply should stay on Alpha 15 after a successful apply.
