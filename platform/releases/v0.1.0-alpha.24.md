# Aidee v0.1.0 Alpha 24

## Purpose

Dashboard and container waits last 240s with a 15s heartbeat. Alpha 23
died at 90s while Control Tower was still booting.

Apply skips `build-assistant-image.sh` and `validate-assistant-image.sh`
when `/etc/aidee/images/{tag}.json` is already validated for this commit
and the image exists.

## Apply

- `wait_healthy` and `wait_dashboard` poll for 240 attempts.
- `ensure_assistant_image` reuses a matching validated image record.

## Migration

No new state migration. Re-run the fleet updater after this tag is active.

## Validation

- Unit tests cover the long dashboard poll and the skip-rebuild path.
- Repository validation and unit tests pass.

## Rollback

Roll back host and assistant image state to `v0.1.0-alpha.23`.
