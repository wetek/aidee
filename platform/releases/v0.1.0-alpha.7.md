# Aidee v0.1.0 Alpha 7

## Purpose

Align assistant dashboard branding dynamically with assistant identity and streamline Telegram onboarding.

## Assistant branding & dashboard synchronization

- Auto-generate assistant skin definitions (`skins/<id>.yaml`) with dynamic display names and response labels.
- Configure `display.skin` in `config.yaml` to ensure the web dashboard and interface match assistant identity.
- Auto-inherit verified owner dashboard credentials (`mehdi`) for seamless single sign-on across the fleet.

## Proactive Telegram onboarding

- Automated Chat Menu Button setup (`setChatMenuButton`) pointing to the assistant's Tailscale dashboard URL.
- Platform-aware mobile guidance avoiding unclickable custom ports in plain bio text.
- Proactive avatar discovery from repository brand assets (`public/brand/*`).
- Defaulting to least-privilege repository credentials (SSH Deploy Keys or fine-grained PATs instead of broad OAuth).

## Shared instructions

- Added `platform/shared-instructions/assistant-onboarding.md`.
- Updated `provision-assistant` skill with identity onboarding and credential inheritance.
