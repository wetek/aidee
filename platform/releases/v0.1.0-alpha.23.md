# Aidee v0.1.0 Alpha 23

## Purpose

The installed administration helper no longer imports `release` at listen
time. Alpha 22 crash-looped with `ModuleNotFoundError: No module named
'release'` because `/usr/local/lib/aidee/aidee-admin` has no sibling
`release.py`. Apply can create the admin socket again.

## Apply

- `aidee_admin.py` loads the assistant-request schema without `pin_schema`.
- The helper starts from the installed layout with only
  `assistant_state.py` and `onboarding_state.py` beside it.

## Migration

No new state migration. Re-run the fleet updater after this tag is active
so the helper is reinstalled. Do not re-apply Alpha 22.

## Validation

- Unit tests import the installed helper without a sibling `release.py`.
- Repository validation and unit tests pass.

## Rollback

Roll back host and assistant image state to `v0.1.0-alpha.22`.
