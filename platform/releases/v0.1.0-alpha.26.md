# Aidee v0.1.0 Alpha 26

## Purpose

Telegram apply no longer dies when the controller gateway restarts.
Alpha 25 stopped after the host and image moved because refreshing
`hermes-gateway.service` killed the updater.

## Apply

- Apply started from Telegram continues as `aidee-fleet-update.service`.
- Gateway unit files refresh without restarting the running process.
- Apply writes `/var/lib/aidee/fleet/UPDATE_STATUS.json`.
- The updater sends a Telegram result, then restarts the gateway.

## Migration

No new state migration. Re-run the fleet updater after this tag is active.

## Validation

- Unit tests cover detach, deferred gateway restart, update status, and
  the owner notice.
- Repository validation and unit tests pass.

## Rollback

Roll back host and assistant image state to `v0.1.0-alpha.25`.
