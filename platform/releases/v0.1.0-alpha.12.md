# Aidee v0.1.0 Alpha 12

## Purpose

Publish the repository's coding-agent skills and standardize where assistants
store repositories used for coding tasks.

## Repository-local skills

- The root `.agents/` directory is no longer ignored.
- Coding agents that clone Aidee receive the repository's skills.

## Assistant repository workspace

- Provisioning creates `/opt/data/aidee/repos` in every assistant's private
  runtime data.
- Assistant instructions require coding-task repositories to stay under that
  directory.
- The controller's provisioning skill uses the same path when connecting or
  cloning repositories.

## Migration

Existing assistants keep their current repository locations. Recreate the
directory as `/opt/data/aidee/repos` or reprovision the assistant before its
next coding task.

## Validation

- Repository validation and unit tests cover the workspace creation and
  assistant instruction.
- Shell syntax and ShellCheck validation pass.

## Rollback

Roll back host and assistant image state to `v0.1.0-alpha.11`. Repository files
under `/opt/data/aidee/repos` remain in the assistant's private runtime state.
