# Aidee v0.1.0 Alpha 17

## Purpose

Show live progress during a fleet apply. Alpha 16 swallowed subprocess
output, so the image build and container waits looked idle.

## Updater progress

- `update-host.sh` prints when it fetches a tag or uses a cached checkout.
- Apply prints numbered `[n/N]` steps that match the preview plan.
- The assistant image build, image validation, Hermes runtime update, and
  controller knowledge sync stream to the terminal.
- Container and dashboard waits print `Still waiting for ... (15s)...`
  while they poll.

## Migration

No new state migration. Re-run the fleet updater after this tag is active.

## Validation

- Unit tests cover numbered progress lines, wait heartbeats, and streamed
  command exit status.
- Repository validation and unit tests pass.

## Rollback

Roll back host and assistant image state to `v0.1.0-alpha.16`.
