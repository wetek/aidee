# Aidee v0.1.0 Alpha 11

## Purpose

Activate the complete 9-skill Matt Pocock engineering suite, default interactive Telegram choices, unslop communication standards, and automated fleet update synchronization.

## 9-Skill Matt Pocock engineering suite

- Bundles the full `.agents/skills` engineering suite in `platform/shared-skills/`:
  - `code-review`: Two-axis diff review (Standards & Fowler smell baseline + Spec fidelity).
  - `codebase-design`: Deep-module architecture (maximizing behavior behind small interfaces at clean seams).
  - `diagnosing-bugs`: 6-phase disciplined debugging loop (`Reproduce → Minimise → Hypothesise → Instrument → Fix → Regression-test`).
  - `domain-modeling`: Ubiquitous domain language, glossary in `CONTEXT.md`, and ADR recording.
  - `grill-me`: Requirements interrogation, edge-case probing, and decision tree exploration before coding.
  - `grill-with-docs`: Grilling paired with inline architecture and ADR documentation.
  - `grilling`: Core interview protocol and decision-tree exploration engine.
  - `handoff`: State preservation, task snapshots, and context handoffs between turns/sessions.
  - `to-spec`: Discussion synthesis into actionable technical specs and tickets.
- Automatically installs all 9 skills into assistant runtime `skills/` directories on creation and fleet update sync.

## Interactive Telegram choices

- Configures mandatory directive in `build_soul_document` instructing assistants to use interactive choice tools (`clarify`) with clickable buttons whenever presenting choices, decisions, next steps, or confirmation requests on Telegram.

## Automated fleet update synchronization

- Introduces `platform/controller-tools/sync-fleet-assistants.py` to automatically update all registered assistants' `SOUL.md`, skills, and runtime standards across platform updates.
- Hooks fleet assistant synchronization directly into `sync-controller.sh --apply` so existing assistants immediately receive new platform directives upon release sync.
