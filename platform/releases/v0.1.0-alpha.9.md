# Aidee v0.1.0 Alpha 9

## Purpose

Fix assistant runtime memories permissions and automate Telegram home channel configuration.

## Assistant memories & container permissions

- Explicitly seeds `runtime_dir / "memories"` with `CONTAINER_UID` (`10000`) and initial `MEMORY.md` and `USER.md` files.
- Recursively enforces runtime tree ownership (`CONTAINER_UID:controller_gid` with `0o770` permissions) across `runtime_dir` prior to container startup.
- Eliminates host root permission shadowing on assistant memories, preventing turn-loop compression crashes.

## Automated home channel setup

- Automatically configures `platforms.telegram.home_channel` in assistant `config.yaml` from controller settings or owner record, eliminating redundant `/sethome` setup prompts.
