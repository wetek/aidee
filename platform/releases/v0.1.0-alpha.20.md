# Aidee v0.1.0 Alpha 20

## Purpose

Finish leftover-clone relocation when the canonical name is a dangling
symlink. Alpha 19 failed Control Tower apply with Errno 20 because
`aidee/repos/control-tower` was a host-invisible `/opt/data/...` link.

## Relocate

- Occupancy uses `lstat`, so a dangling symlink counts as taken.
- A real checkout at that name stays. The leftover clone moves to
  `aidee/legacy-home-repos`.
- A file or symlink at that name moves to `legacy-home-repos` instead, and
  the leftover clone takes the canonical path.

## Migration

No new state migration. Re-run the fleet updater after this tag is active.
`003_alpha18_relocate_home_repos` still runs if it did not finish.

## Validation

- Unit tests cover leftover clones against a dangling symlink and a file at
  the canonical name.
- Repository validation and unit tests pass.

## Rollback

Roll back host and assistant image state to `v0.1.0-alpha.19`.
