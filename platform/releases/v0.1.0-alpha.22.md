# Aidee v0.1.0 Alpha 22

## Purpose

Daily update notices can send tap-to-send Telegram buttons. Hermes cron
cannot use clarify, so the Alpha 21 notice printed numbered Options that
did nothing. A tap is a normal message. Continuity then runs preview.
Apply now still uses clarify because that turn is interactive chat.

The current tag lives only in `LATEST`. A bump writes that file, adds
release notes, adds one README line, and tags. Schemas, examples, and
guides no longer copy the tag.

## Apply

- Cron update notices pipe to `send-telegram-choices.py` with Start update
  and Not now. The first delivery still does not apply.
- Setup plans, image requests, and `setup.sh` read `LATEST` through
  `platform/release.py`.

## Migration

No new state migration. Re-run the fleet updater after this tag is active
so the daily cron prompt and controller-update skill install. The notice
already received will not grow buttons. The next check after this apply
will.

## Validation

- Unit tests cover Telegram choice payloads and LATEST binding.
- Repository validation and unit tests pass.
