# Aidee v0.1.0 Alpha 4

## Purpose

Make Telegram branding optional and let installed controllers load new Aidee knowledge without root access.

## Controller onboarding

The controller must offer Telegram branding in its first authorized conversation. The owner may:

- Configure it now.
- Defer it.
- Keep the current profile.

Applied, deferred, and skipped choices satisfy the branding gate. A pending choice does not.

Telegram owner authorization and phone dashboard verification remain required.

## Controller knowledge sync

An installed controller can:

- Fetch a tagged Aidee release into its private cache.
- Preview release notes without changing active skills.
- Ask the owner for approval.
- Refresh versioned Aidee skills after approval.
- Report when the root-owned host installation remains older.

The sync script rejects root execution. It does not modify `/opt/aidee`, system packages, or system services.

## Daily update check

The controller can create one idempotent Hermes cron job that checks every 24 hours. It stays silent when no update exists. When a newer release appears, it previews the changes and asks the owner before syncing.

The cron job never applies updates.

## Not included

- Automated root-owned host upgrades.
- Cloudflare dashboard adapter.
- Assistant container provisioning.
