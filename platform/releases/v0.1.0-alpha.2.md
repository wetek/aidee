# Aidee v0.1.0 Alpha 2

## Purpose

Replace narrated host setup with one resumable setup program.

## Setup interface

- Start: `sudo ./setup.sh --plan setup-plan.json`
- Resume: `sudo ./setup.sh`
- Status: `sudo ./setup.sh --status`

## Included

- Validated non-secret JSON setup plan.
- Host preflight and bootstrap.
- Reboot progress.
- Pinned Aidee and Hermes installation.
- Private fleet initialization.
- Loopback controller dashboard.
- Tailscale installation and private dashboard access.
- Model and messaging readiness checks.
- Persistent controller gateway.
- Non-secret Telegram handoff.

## Manual actions

The owner still:

- Connects to the VPS over SSH.
- Pastes the first bootstrap block.
- Reconnects and reruns setup after reboot.
- Approves Tailscale access.
- Creates model and messaging credentials.
- Enters credentials through the private dashboard.

## Not included

- Assistant container provisioning.
- Immediate private Git backup.
- Cloudflare dashboard access.
- Provider firewall automation.

## Validation

The repository checks shell syntax, ShellCheck, schemas, setup plans, template rendering, document links, script paths, and unsafe downloaded-script pipes.
