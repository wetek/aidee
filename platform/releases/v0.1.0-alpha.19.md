# Aidee v0.1.0 Alpha 19

## Purpose

Offer Aidee updates from Telegram. Alpha 18 discovered a newer tag and
sent SSH preview commands.

## Telegram update

- The daily update check sends a short notice with ✨, at most three
  owner-facing bullets, and a Start update / Not now clarify.
- After Start update the controller runs preview with sudo, then offers
  Apply now.
- Apply runs only after that second tap. An unanswered cron notice never
  applies.
- SSH remains a fallback when Telegram clarify is unavailable.

## Migration

No new state migration. Re-run the fleet updater after this tag is active.

## Validation

- Unit tests cover the daily job prompt offering Start update and Apply now.
- Repository validation and unit tests pass.
