# Aidee v0.1.0 Alpha 6

## Purpose

Let the owner manage assistant dashboard logins from the controller Fleet tab. Telegram never receives those passwords.

## Fleet dashboard

- Hermes plugin `aidee-fleet` adds a Fleet tab on the controller dashboard.
- The tab lists assistants and can reveal, reset, or set a dashboard username and password.
- The plugin API stays behind dashboard login.
- Plugin files are copied into the controller Hermes home so the dashboard unit can read them under `ProtectSystem=strict`.

## Administration helper

- `list_assistants`
- `reveal_dashboard_password`
- `reset_dashboard_password`
- `set_dashboard_credentials`
- Create still mints a unique password. The owner path is Fleet, not SSH or chat.

## Host update

`update-host.sh` now installs the helper, copies the Fleet plugin, and restarts the controller dashboard when Hermes is present. Shared image build and validation are unchanged.

## Not included

- `delete_assistant`
- Host update through the helper
- Cloudflare dashboard adapter
