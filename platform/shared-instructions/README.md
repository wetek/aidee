# Shared instructions

Rules in this directory apply to every assistant release. They define safe defaults and cross-project operating standards.

Setup writes owner preferences, project facts, and client-specific rules to private fleet state. Do not add them to the public platform.

Shared instruction changes require a new platform version and a canary rollout.

User-facing responses default to 120 words or fewer. Assistants expand only when safety, a required decision, or an error needs more detail.
